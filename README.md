# bpla-banner-generator
# Генератор патриотических баннеров для курсов БПЛА

## Описание проекта
API-сервис, который автоматически создаёт информационные баннеры с QR-кодами для привлечения граждан к обучению управлению БПЛА и службе в рядах ВС РФ. Баннеры содержат актуальную информацию о центрах подготовки и ведут на официальные ресурсы Минобороны.

## Актуальность
- Помогает гос. пабликам и волонтёрам быстро создавать визуальный контент.
- Направляет целевую аудиторию на проверенные источники информации о курсах операторов БПЛА.
- Поддерживает патриотическое воспитание и информирование о возможностях службы.

## Технологии
- **Backend:** Python 3.12, Yandex Cloud Functions (serverless)
- **Хранение:** Yandex Object Storage (для готовых баннеров)
- **Генерация изображений:** (в текущей версии используется упрощённая генерация, в планах – интеграция с YandexART)
- **Библиотеки:** Pillow, qrcode, boto3, requests
