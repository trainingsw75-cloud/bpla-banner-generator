# Генератор патриотических баннеров для курсов БПЛА

## Описание
API-сервис и веб-интерфейс для автоматического создания информационных баннеров с QR-кодами, направленных на привлечение граждан к обучению управлению БПЛА и службе в ВС РФ. Баннеры содержат актуальную информацию о центрах подготовки и ведут на официальные ресурсы Минобороны.

## Технологии
- **Backend:** Python 3.12, Yandex Cloud Functions (serverless)
- **Хранение:** Yandex Object Storage (для баннеров и статического сайта)
- **Библиотеки:** Pillow, qrcode, boto3, requests
- **Frontend:** HTML, CSS, JavaScript (fetch API)

## Как это работает
1. Пользователь вводит заголовок, город и ссылку через веб-интерфейс.
2. API генерирует изображение (сейчас — fallback, в планах — YandexART) и накладывает QR-код.
3. Готовый баннер сохраняется в Object Storage и отображается пользователю.
